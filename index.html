How it works

Three steps. Nothing leaves your browser.

  1. 01

    Open a file

    Drop a PDF or image in — or click to browse. The file is read straight from disk into memory. No network request is made.

  2. 02

    Mark what to hide

    Drag redaction boxes over content, or paint and pixelate regions of an image. Move, resize, and delete marks freely.

  3. 03

    Export the result

    TrueHide renders a new file with your changes burned in and downloads it. The original data is overwritten, not hidden.

Your privacy matters

Privacy is the point, not a feature.

Most online editors send your files to a server, process them there, and keep whatever they're told to. TrueHide does the opposite: the entire pipeline — rendering, redaction, export — runs on your machine using browser APIs.

Files stay on your device

Documents and images are processed locally with canvas and Web APIs. There is no upload endpoint — the code doesn't contain one.

No accounts, no telemetry

Nothing to sign up for, nothing to track. The site works the same with the network cable unplugged.

Know what each tool does

Blurring and pixelation obscure details but aren't guaranteed irreversible. Solid black redaction and PDF flattening actually destroy the underlying data. TrueHide says so plainly.

The difference

Visual obfuscation (blur, pixelate) makes details hard to read at a glance — a zoomed-in or magnified export may still reveal context. Irreversible redaction (solid black, TrueFlatten) overwrites the pixels or rasterizes the page so the original data can't be recovered. For sensitive information, use the latter.

Installable

Keep the tools on your desktop.

TrueHide is a web app, so install it like a native one: add it to your home screen or taskbar, and it runs as its own window — fully offline.

Install TrueHide

In your browser: “Install app” in the address bar (Chrome, Edge) or “Add to Home Screen” (Safari).
