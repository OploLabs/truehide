**Privacy-first tools for documents and images.**

TrueHide is a collection of privacy-focused tools for editing, redacting, and sanitizing documents and images.

Everything runs locally in your browser. No uploads, no accounts, no tracking, no analytics, and no remote file processing.

[Website](https://oplolabs.github.io/truehide/) · [GitHub](https://github.com/OploLabs/truehide) · [Report a Bug](https://github.com/OploLabs/truehide/issues)

## Applications in Detail

### TrueFlatten

A PDF redaction and flattening application designed to make redactions permanent.

**Features**

- Open and render PDF documents locally.
- Multi-page PDF support.
- Draw redaction regions directly on pages.
- Move existing redactions.
- Delete individual redactions.
- Clear redactions from individual pages.
- Undo and redo.
- Keyboard shortcuts.
- Export flattened PDFs.
- Export verification.

**How it works**

TrueFlatten uses PDF.js to render each PDF page onto a canvas, then uses jsPDF to generate a new PDF from the rendered pages.

This removes the original selectable text and document structures rather than simply placing a black rectangle over existing content.

Automated tests verify that redacted text is no longer extractable, the redaction is visibly rendered, and tested structural content such as annotations, attachments, form fields, and source metadata is not carried into the flattened output.

PDF metadata generated by the export library may remain.

### TrueBlur

An image redaction application with multiple destructive editing effects.

**Available effects**

- Pixelate
- Randomized blocks
- Solid black redaction
- FalsePixel
- Paint / brush

**Features**

- Interactive image selection.
- Destructive image transformations.
- Undo and redo.
- Before-and-after editing.
- Image previews.
- Keyboard shortcuts.
- Local image processing.

Pixelation and randomized blocks are visual obfuscation techniques, not guaranteed irreversible redaction. Use solid black redaction for sensitive information.

### TrueCrop

A precision image cropping application.

**Features**

- Interactive crop selection.
- PNG export.
- JPEG export.
- WebP export.
- Undo and redo.
- Reset selection.
- Filename customization.
- Export preview.
- Image dimension information.
- Transparency preservation for PNG.
- Image format validation.

TrueCrop processes images locally using the Canvas API.

### TrueMetadata

An image metadata inspection and removal application.

**Features**

- Inspect image metadata.
- View EXIF information.
- Inspect XMP metadata.
- Identify GPS and location information.
- Inspect supported embedded text.
- Remove supported metadata.
- Export cleaned images.
- Re-read exported files for verification.

The goal is to remove information that may unintentionally reveal details about an image's origin, camera, location, or editing software.

## Why TrueHide?

Most online document and image editors require uploading files to remote servers.

TrueHide takes a different approach.

**Your files stay on your device.**

- **Local processing:** Document and image processing happens inside your browser.
- **No uploads:** Files are never sent to remote processing services.
- **No tracking:** No analytics, telemetry, or advertising trackers.
- **No accounts:** No registration or sign-in required.
- **Offline support:** Applications can continue working without an internet connection after their assets are cached.
- **Self-hosted assets:** Fonts and third-party libraries are stored locally.
- **Open source:** Inspect the implementation and verify the privacy claims.
- **PWA support:** Installable on compatible desktop and mobile browsers.

## Privacy

Privacy is the foundation of TrueHide.

### Network behavior

TrueHide is designed to operate without external resource requests.

- No file uploads.
- No remote processing.
- No analytics.
- No telemetry.
- No tracking.
- No external font requests.
- No CDN dependencies.

Files are read into browser memory using local file inputs and drag-and-drop functionality.

Automated network monitoring tests verify that application requests remain local. In-memory `blob:` and `data:` URLs are used for browser operations.

### Local assets

Application resources are hosted within the repository.

- Inter font: `fonts/inter-latin.woff2`
- PDF.js: locally vendored.
- jsPDF: locally vendored.
- Shared styles and scripts: locally hosted.

No Google Fonts or external CDNs are required.

### Offline support

TrueHide uses a service worker with a cache-first strategy.

The service worker:

- Caches application assets.
- Supports offline application loading.
- Supports offline navigation to individual applications.
- Provides an offline navigation fallback.
- Keeps the applications functional after their resources have been cached.

The verified service worker cache contains 31 application shell entries.

## Security Considerations

TrueHide is designed to improve privacy, but different operations provide different levels of protection.

### Image redaction

Pixelation and randomized blocks are visual obfuscation techniques. They should not be treated as guaranteed irreversible redaction.

For highly sensitive information, use solid black redaction.

### PDF redaction

TrueFlatten rasterizes PDF pages before exporting them.

This removes original selectable page text and tested document structures from the resulting PDF.

However, metadata generated by the PDF export library may remain. TrueFlatten is not a complete PDF metadata sanitization tool.

### Image metadata

TrueMetadata removes supported image metadata and verifies the exported result by reading it again.

Verification is limited to the supported metadata formats and structures.

### General recommendation

Always inspect exported files before sharing them.

Automated verification provides additional confidence, but it does not replace reviewing the actual output.

## Technology Stack

TrueHide uses standard browser technologies without a frontend framework or application build process.

| Technology          | Purpose                                 |
| ------------------- | --------------------------------------- |
| HTML5               | Application structure                   |
| CSS3                | Styling, themes, and responsive layouts |
| Vanilla JavaScript  | Application logic                       |
| Canvas API          | Image rendering and manipulation        |
| PDF.js 3.11.174     | PDF rendering                           |
| jsPDF 2.5.1         | PDF generation                          |
| Web APIs            | File handling and downloads             |
| Service Workers     | Offline support                         |
| PWA                 | Installable application experience      |
| Playwright          | Browser automation and E2E testing      |
| Node.js `node:test` | Unit testing                            |
| axe-core            | Accessibility testing                   |

Third-party runtime libraries are vendored locally.

There is no frontend framework, bundler, transpiler, or application compilation step.

The root `package.json` exists exclusively for development and testing.

## Development

### Requirements

- A modern browser.
- Node.js.
- npm.

### Clone the repository

```bash
git clone https://github.com/OploLabs/truehide.git
cd truehide
```

### Run locally

Using `npx serve`:

```bash
npx serve .
```

Or using Python:

```bash
python -m http.server 8080
```

Visit:

```text
http://localhost:8080
```

Opening `index.html` directly is also possible, but HTTP or HTTPS is recommended for service worker and PWA functionality.

### Install development dependencies

```bash
npm ci
npx playwright install
```

### Verification limitations

Automated tests do not establish complete security or accessibility certification.

The latest documented verification report identifies these limitations:

- No full manual NVDA or VoiceOver walkthrough.
- Pointer-driven controls have not been fully verified for keyboard-only operation.
- WCAG 2.2 AA conformance has not been established.
- Firefox WebP downloads require a different automated verification approach because of Playwright download-event limitations.
- PDF export metadata is not completely sanitized.
- Undo history has memory-bounded limits.

The CI workflow is authored, but the verification report does not establish a successful GitHub Actions execution.

See [VERIFICATION_REPORT.md](./VERIFICATION_REPORT.md) for the detailed results, test methodology, and limitations.
