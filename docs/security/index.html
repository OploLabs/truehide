TrueHide — Security & privacy

Core claim

Every file you open in TrueFlatten, TrueBlur, TrueCrop, or TrueMetadata is processed entirely in your browser. No file contents are uploaded, sent to a server, or stored anywhere permanent.

What we handle (and how)

PDFs (TrueFlatten)
Rasterized at 2× scale; redaction boxes are black rectangles drawn on the canvas. Source text, annotations, form fields, and embedded files are not included in the exported PDF because jsPDF rebuilds the file from the rendered image. jsPDF adds its own XMP metadata (producer/creator).
Images (TrueBlur)
Canvas‑based effects (pixelate, blocks, solid black, FalsePixel, paint). All rendering stays on‑device. The "solid black" and "block" modes produce irreversible redaction; pixelate and FalsePixel are visual obfuscation only.
Images (TrueCrop)
Canvas crop + PNG/JPEG/WebP export. The export preserves or discards alpha per the chosen format. JPEG fills transparent areas with white.
Image metadata (TrueMetadata)
EXIF, XMP, PNG text chunks, and WebP metadata chunks are read and stripped at the byte level — no pixel data is touched. The cleaned export is re-read by the same parser to verify nothing metadata-like remains. Unsupported containers (TIFF, HEIC, GIF, PDF) are shown as unsupported rather than cleaned silently.

What we never send off‑device

  • Raw file bytes or disk paths
  • Any user‑identifying information
  • Usage analytics, telemetry, or crash reports
  • Data to any CDN or third‑party service

Former external request — now self‑hosted

The site formerly loaded Inter from Google Fonts (@import in shared/base.css). It is now self‑hosted at fonts/inter-latin.woff2. No network request leaves the device.

Local storage

The only data persisted in localStorage is the user's colour‑scheme preference (truehide-theme), stored as "light" or "dark". No file contents, no IDs.

Redaction limitations

  • Canvas effects (TrueBlur pixelate/blocks/FalsePixel/paint): visual obfuscation only — the original pixel data remains on the canvas until overwritten.
  • TrueFlatten PDF redaction: permanent at the pixel level because the output is a fresh rasterized PDF, but source annotations, AcroForm fields, and embedded files are stripped by the rasterization process; the output still carries jsPDF‑generated XMP metadata.
  • TrueCrop JPEG export: transparency is lost — the background fills with white.
  • TrueMetadata removal: stripping is container‑level (EXIF blocks, XMP blocks, PNG text chunks) — selecting a category still removes the whole block it lives in, which only over‑removes. The cleaned export is re‑read to verify; a canvas re‑encode fallback may change JPEG/WebP quality slightly. ICC color profiles are intentionally kept.

Vulnerability disclosure

Report security or privacy issues by opening an issue on the GitHub repository (github.com/OploLabs/truehide/issues/new). Reports are acknowledged within 48 hours. The project follows a coordinated disclosure policy; there is no bug‑bounty program at this time.
